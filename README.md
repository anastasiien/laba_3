# Мини-облако: хостинг виртуальных машин и контейнеров

Учебный прототип облачного провайдера: пользователь через веб-панель создает виртуальную машину (QEMU) или контейнер (Docker) с нужными ресурсами, получает SSH-доступ и видит, сколько ресурсов израсходовал и сколько это стоит. Фоновый монитор следит за лимитами и останавливает машины, которые их превысили.

## Возможности

- создание **виртуальной машины** (QEMU, с KVM-ускорением, если доступно) или **контейнера** (Docker)
- выбор ОС: Ubuntu 22.04 / 20.04, Debian 12, Alpine 3.18, Fedora 38
- настройка CPU, RAM, диска и лимита процессорного времени
- предварительный расчет стоимости в час и в сутки
- SSH-доступ к каждой машине через отдельный порт
- учет потребления: процессорное время, трафик, накопленная стоимость
- остановка и перезапуск
- автоматическая остановка при превышении лимита CPU, трафика или времени работы

## Архитектура

```
app.py (Streamlit-панель)
   │
   ▼
api/api.py ─────────────── api/state.py   (хранилище инстансов)
   │         │             api/models.py  (модели, тарифы, лимиты)
   ▼         ▼
qemu/      docker_manager/
qemu_manager.py   docker_manager.py
   ▲
monitor/monitor.py (фоновый поток: каждые 10 секунд обновляет потребление и проверяет лимиты)
```

| Модуль | Что делает |
|---|---|
| `api/models.py` | модели данных (`Instance`, лимиты, потребление, SSH), статусы, причины остановки, тарифы |
| `api/state.py` | хранилище инстансов в памяти и статистика |
| `api/api.py` | бизнес-логика: создание, остановка и перезапуск машин, учет потребления, расчет цены. Если модуль QEMU или Docker не подключается, переключается на заглушки |
| `qemu/qemu_manager.py` | запуск VM: copy-on-write диск поверх базового образа (`qemu-img -b`), проброс SSH-порта, управление процессом через pid-файл |
| `docker_manager/docker_manager.py` | запуск контейнера с лимитами CPU и памяти, установка SSH-сервера, сбор статистики CPU и трафика |
| `monitor/monitor.py` | фоновый поток контроля лимитов |
| `app.py` | веб-панель на Streamlit |

**Тарифы:** 5 ₽ за ядро в час, 2 ₽ за ГБ RAM в час, 0.1 ₽ за ГБ диска в час.

## Запуск

Нужны Python 3.10+, Docker (для контейнеров) и QEMU (для виртуальных машин).

```bash
pip install -r requirements.txt
streamlit run app.py
```

Для виртуальных машин нужны базовые образы дисков в формате qcow2: `images/base/<ОС>.qcow2`, например `images/base/ubuntu-22.04.qcow2`.

> Это учебный прототип: состояние хранится в памяти, а SSH в контейнерах настроен с тестовым паролем. Для реального использования так делать нельзя.
